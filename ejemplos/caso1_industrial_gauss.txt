MÉTODO DE GAUSS  (eliminación hacia adelante + sustitución hacia atrás)

Sistema:
  Ec.1:  2·x1 + 3·x2 + 4·x3 = 140
  Ec.2:  x1 + 2·x2 + x3 = 65
  Ec.3:  3·x1 + x2 + 2·x3 = 80

Matriz aumentada [A | b]:
    [ 2 3 4 | 140 ]
    [ 1 2 1 |  65 ]
    [ 3 1 2 |  80 ]

FASE 1 · Eliminación hacia adelante (se busca una matriz escalonada)

F2 ← F2 − 1/2·F1      [m = 1/2 = 1/2]
    [ 2   3  4 | 140 ]
    [ 0 1/2 -1 |  -5 ]
    [ 3   1  2 |  80 ]

F3 ← F3 − 3/2·F1      [m = 3/2 = 3/2]
    [ 2    3  4 |  140 ]
    [ 0  1/2 -1 |   -5 ]
    [ 0 -7/2 -4 | -130 ]

F3 ← F3 + 7·F2      [m = (-7/2)/(1/2) = -7]
    [ 2   3   4 |  140 ]
    [ 0 1/2  -1 |   -5 ]
    [ 0   0 -11 | -165 ]

Matriz final:
    [ 2   3   4 |  140 ]
    [ 0 1/2  -1 |   -5 ]
    [ 0   0 -11 | -165 ]

ANÁLISIS: rango(A) = rango([A|b]) = 3 = número de incógnitas → solución única.

FASE 2 · Sustitución hacia atrás

De la fila 3:  -11·x3 = -165
   x3 = (-165) / (-11) = 15
De la fila 2:  1/2·x2 - x3 = -5
   x2 = (-5 - (-1)·15) / (1/2) = 20
De la fila 1:  2·x1 + 3·x2 + 4·x3 = 140
   x1 = (140 - 3·20 - 4·15) / 2 = 10

RESULTADO: solución única
  x1 = 10
  x2 = 20
  x3 = 15

VERIFICACIÓN (sustitución en el sistema original):
  Ec.1: 2·10 + 3·20 + 4·15 = 140   (b = 140)  ✓
  Ec.2: 1·10 + 2·20 + 1·15 = 65   (b = 65)  ✓
  Ec.3: 3·10 + 1·20 + 2·15 = 80   (b = 80)  ✓
  ➜ La solución satisface todas las ecuaciones.

INTERPRETACIÓN EN EL CONTEXTO DEL CASO
Una planta fabrica sillas (x1), mesas (x2) y escritorios (x3). Cada unidad consume horas en tres estaciones: corte, ensamblaje y acabado. Se desea saber cuántas unidades producir para usar EXACTAMENTE las horas disponibles: 140 h de corte, 65 h de ensamblaje y 80 h de acabado.

  • Sillas: 10 unidades
  • Mesas: 20 unidades
  • Escritorios: 15 unidades
  ➜ Solución factible: todas las cantidades son no negativas.

Resumen

El programa construye un sistema de ecuaciones lineales a partir de un caso real, lo verifica y lo resuelve por el método que el usuario elija. Usa fracciones exactas (sin errores de redondeo), valida las entradas, clasifica el sistema (solución única, infinitas soluciones o sin solución) y comprueba la solución por sustitución.

Construir y validar

Sistemas 3×3 o 4×4 con enteros, decimales o fracciones. Avisa de campos vacíos, texto no numérico y determinante cero.

Resolver paso a paso

Cada operación por filas, cada determinante y cada producto de la inversa quedan documentados.

Verificar y comparar

Sustitución en las ecuaciones y comparación de los cuatro métodos en operaciones y tiempo.

Casos de estudio

Industrial · Planta de muebles 3×3

Sillas (x₁), mesas (x₂) y escritorios (x₃) consumen horas de corte, ensamblaje y acabado. ¿Cuánto producir para usar exactamente las horas disponibles?

2x₁ + 3x₂ + 4x₃ = 140
 x₁ + 2x₂ +  x₃ =  65
3x₁ +  x₂ + 2x₃ =  80

Sistemas · Clúster de servidores 4×4

Consultas SQL, transacciones web, reportes batch y respaldos consumen CPU, RAM, disco y red. ¿Qué carga agota exactamente la capacidad?

2x₁ +  x₂ +  x₃       = 28
 x₁ + 3x₂ + 2x₃ +  x₄ = 55
       x₂ + 4x₃ + 2x₄ = 50
 x₁       +  x₃ + 3x₄ = 25
